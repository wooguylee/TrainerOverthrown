# VVooOverthrown 사용 가이드

## 설치

1. Overthrown을 완전히 종료한다.
2. `VVooOverthrown.exe`를 실행한다.
3. 게임 경로가 `W:\Games\Overthrown`인지 확인한다.
4. `한글 패치 설치`를 누른다. 설치 전에 사용자 데이터가 자동 백업된다.
5. `게임 실행`을 누른다. 첫 실행은 IL2CPP interop 생성 때문에 평소보다 오래 걸릴 수 있다.

현재 지원 빌드와 해시가 다르거나 대상 파일이 이미 있으면 설치하지 않는다. 다른 BepInEx
모드가 설치된 폴더를 자동으로 덮어쓰지 않는다.
설치 후 게임이 업데이트되어 해시가 달라져도 Helper가 게임 시작 시 세 파일을 다시
검증하고 trainer pipe와 변경 기능을 열지 않는다.

## 한글 패치

- 영어 원본 Addressables 번들을 수정하거나 교체하지 않는다.
- 사용자에게 노출되는 번역 가능 항목 1,573/1,586개 안정 키가 검수 상태다.
- 같은 원문의 중복을 합친 실제 런타임 사전은 1,394개다.
- 남은 13개는 법적 효력을 가진 EULA 원문 1개, 개발자가 의도적으로 비운 설명 5개,
  화면 구분용 `-` 7개다. 비공식 번역으로 의미를 바꾸지 않고 원문 상태를 유지한다.
- 맑은 고딕 기반 TextMeshPro 동적 fallback으로 한글 글리프를 표시한다.

## 트레이너

1. 게임 월드에 들어간다.
2. 앱에서 `상태 새로고침`, `Helper 연결`을 순서대로 누른다.
3. `테스트 모드` 상태가 표시되면 기능 버튼이 활성화된다. 로컬/원격/미확인 세션
   판정은 `진단` 탭에 원시 정보로 남지만 기능을 잠그지는 않는다.
4. 필요한 기능 탭을 선택한다.

- `플레이어`: 체력 즉시 회복, 무적, 기력 회복 배율 `0x`~`100x`
- `이동·시간`: Ctrl 신속 이동 무한, 로컬 이동 속도 `0.1x`~`20x`, 월드 시간 `0x`~`10x`
- `인벤토리`: 선택한 자원의 현재값 조회, 설정, 추가, 차감
- `왕국 자원`: 전역 저장소 자원의 현재값 조회, 설정, 추가, 차감
- `진단`: 세션 신호, 게임 객체 준비 상태, capability, 일시 변경값 복원

현재 빌드의 세 파일 해시가 다르면 Helper 자체가 시작되지 않는다. 플레이어나 저장소가
아직 로드되지 않은 기능은 다른 기능을 잠그지 않고 `FEATURE_UNAVAILABLE`로만 실패한다.
`Ctrl 신속 이동 무한`은 기력 회복을 `100x`로 설정하고 로컬 플레이어의 신속 이동
쿨다운을 제거한다. 공중 돌진 횟수 제한과 공격·피격·사망·건설 같은 행동 제한은 유지한다.
앱 종료와 Helper 연결 해제 시 무적·기력·Ctrl 신속 이동·이동 속도·시간 배속은 원래 값으로 복원한다.
인벤토리와 왕국 자원 변경은 저장되는 게임 상태이므로 자동 복원하지 않는다.

## 제거와 복구

- 게임을 종료하고 앱의 `안전하게 제거`를 누른다.
- manifest에 기록된 VVooOverthrown 소유 파일만, 설치 당시 해시와 같은 경우에만 제거한다.
- 사용자가 변경한 파일은 보존한다.
- 백업 기본 위치: `%LOCALAPPDATA%\VVooOverthrown\Backups`

명령행 설치·제거도 지원한다.

```powershell
.\VVooOverthrown.exe --install --game 'W:\Games\Overthrown'
.\VVooOverthrown.exe --remove --game 'W:\Games\Overthrown'
```
